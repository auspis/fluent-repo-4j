# Release Notes - v1.3.0

Release date: 2026-05-02

## Highlights

The introduction of **Build Hooks** makes monitoring PreparedStatement construction effortless.

You can now log statement details out of the box by enabling the following JVM arguments:

`-Dfluentsql.hooks.build.logging.enabled=true -Dfluentsql.hooks.build.logging.includeParams=true`
